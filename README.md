# 🚔 Police Data System – Integrated Police Database System

## 📖 Overview

Police Data System is an advanced digital platform designed to simplify the management of security information, citizen records, and vehicle data within cities and Roleplay servers. The system provides a centralized database that allows officers to quickly access information, register new records, and manage data securely and efficiently.

The platform features a modern and user-friendly interface that enables users to search for citizens and vehicles using license plate numbers or identification numbers, displaying all related information instantly. It also supports adding new citizens, registering vehicles, and linking each vehicle to its owner within the database.

---

## 🔍 Advanced Search System

The system includes a fast and efficient search engine that allows officers to access citizen and vehicle information within seconds. Search results provide detailed information, including:

* Full Name
* Age
* Date of Birth
* Occupation
* Phone Number
* Address
* National ID Number
* Linked Vehicle Information

---

## 👤 Citizen Management

Users can add and manage citizen records through a simple interface, making identity verification and information tracking easier and more organized.

---

## 🚗 Vehicle Management

The platform allows officers to register vehicles and directly link them to their owners through identification numbers.

Vehicle records include:

* License Plate Number
* Vehicle Model
* Vehicle Color
* Manufacturing Year
* Vehicle Status:

  * Clean
  * Wanted
  * Stolen
  * Impounded

---

## 📋 Security Records

A dedicated section is available for managing:

* Violations
* Reports
* Notes
* Criminal Records

This helps organize police operations and improves information accessibility.

---

## ☁️ Firebase Realtime Database

The project uses Firebase Realtime Database to store and synchronize data in real time. All changes are instantly updated across connected users without requiring page refreshes.
